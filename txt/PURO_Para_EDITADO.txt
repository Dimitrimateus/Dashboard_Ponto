Option Explicit

' ================================================================================
' MACRO: PURO_Para_EDITADO
' --------------------------------------------------------------------------------
' OBJETIVO
'   Ler os dados brutos da aba "PURO" (exportação do sistema de ponto) e gerar
'   uma nova aba, no formato "EDITADO_MESANO" (ex.: EDITADO_AGO26), já no layout
'   final usado para conferência/gestão, incluindo:
'     - Reordenação e renomeação de colunas
'     - Conversão de flags "X" para "SIM" nas colunas de marcação
'     - Inclusão das colunas manuais em branco (Gestor, Situação, Tratamento,
'       Pontonet), que não existem na PURO e são preenchidas à mão depois
'     - Descarte das colunas que não são usadas na EDITADO (Empr, T, Local,
'       Descrição, Column1)
'     - Remoção dos espaços sobrando no início/fim de TODOS os textos (nomes,
'       marcações, flags e cabeçalhos). A exportação do sistema preenche os
'       campos com espaços até uma largura fixa ("FULANO DE TAL      "), o que
'       atrapalha filtros, PROCV/XLOOKUP e comparações. Ver LimparTexto.
'
' POR QUE É "À PROVA DE ERROS"
'   1) Cada linha da PURO é processada de forma INDEPENDENTE (não existe
'      "amarração" linha a linha com uma EDITADO antiga). Isso significa que a
'      macro funciona igual mesmo que no mês seguinte tenham entrado ou saído
'      funcionários: ela simplesmente gera uma linha na EDITADO para cada linha
'      que existir na PURO naquele mês, seja 90, 111 ou 150 linhas.
'   2) As colunas são localizadas na PURO PELO NOME DO CABEÇALHO (e não pela
'      letra/posição). Se o sistema mudar a ordem das colunas na exportação,
'      a macro continua funcionando.
'   3) Se algum cabeçalho esperado não for encontrado na PURO, a macro avisa
'      o usuário (lista o que faltou) e segue em frente deixando a coluna
'      correspondente em branco na nova aba, em vez de travar com erro.
'   4) O nome da nova aba é gerado automaticamente a partir da data de apuração
'      mais recente encontrada na PURO (ex.: EDITADO_AGO26). Se já existir uma
'      aba com esse nome (rodou 2x no mesmo mês), a macro pergunta se deve
'      sobrescrever ou criar uma cópia numerada (EDITADO_AGO26 (2)).
'   5) Copia o formato de número (data/hora) da PURO para a nova aba, célula a
'      célula, então os valores continuam aparecendo como hora (hh:mm) ou data,
'      e não como número serial do Excel.
'   6) Usa tratamento de erro (On Error) em blocos críticos e restaura o estado
'      do Excel (cálculo automático, alertas etc.) mesmo se algo falhar no meio
'      do processo.
'
' COMO USAR
'   1) Abra o Editor VBA (Alt+F11) na planilha que contém a aba PURO.
'   2) Menu Arquivo > Importar Arquivo... e selecione este .bas
'      (ou copie/cole o conteúdo em um Módulo novo).
'   3) Volte à planilha, pressione Alt+F8, selecione "PURO_Para_EDITADO"
'      e clique em Executar.
'   ATENÇÃO: prefira COPIAR/COLAR. "Importar Arquivo" lê o .bas como ANSI e
'   estraga os acentos (o .bas está em UTF-8), e aí a busca de cabeçalhos com
'   acento ("Situação", "Dt.Apuraç.", "Marcações") deixa de achar a coluna.
' --------------------------------------------------------------------------------
' COMO SE LIGA AO RESTO DO PROJETO
'   aba PURO (exportação de ocorrências do sistema) -> esta macro -> aba
'   EDITADO_<MES><AA> -> o RH trata as ocorrências nessa aba (preenche Gestor,
'   Situação, Tratamento, Pontonet) e ela vira a aba "Tratamento" (ou
'   "Tratamento - Internos"/"Tratamento - Externos") -> o GerarAbaCSV
'   (GerarCSVPonto) lê essa aba pelos NOMES de cabeçalho e gera as ocorrências do
'   CSV -> painel (index.html). Por isso os nomes em targetHeaders (passo 3)
'   não devem mudar sem conferir o GerarCSVPonto.
'   Não depende de nenhum outro módulo (LimparTexto está no fim deste arquivo).
'
' COLAR NAS ABAS DE TRATAMENTO (29/10)
'   Depois de montar a EDITADO, a macro separa as linhas pela coluna "Tipo de
'   trabalho" da aba ORG (achada pela matrícula; se a matrícula não estiver no
'   ORG, pelo nome) e cola os internos na aba "Tratamento - Internos" e os
'   externos na "Tratamento - Externos", achando cada coluna pelo NOME do
'   cabeçalho da aba de destino:
'     Matricula, Nome, Situação, Data (<- Dt.Apuraç.), Status (<- Tratamento),
'     Pontonet (só existe na de Externos), Marcações ... Refeição fora de Escala
'       -> vêm da EDITADO;
'     Trabalho, Cargo, Gestor -> se a aba já tem FÓRMULA nessas colunas (ex.:
'       PROCX no ORG), a fórmula é estendida para as linhas novas; se não tem,
'       o valor vem do ORG (Tipo de trabalho, Cargo, GESTOR);
'     Check -> fica em branco (o RH marca).
'   A macro é usada TODO DIA: ela nunca apaga nada das abas de tratamento. Se a
'   aba já tem linhas, pergunta: OK = colar embaixo das que existem, Cancelar =
'   não colar. Quem não está no ORG (ou está sem "Tipo de trabalho") não é
'   colado: a linha fica AMARELA na EDITADO. Toda pessoa com informação faltando
'   no ORG (não está lá, sem Tipo de trabalho, Cargo ou Gestor) aparece na aba
'   "Avisos ORG", refeita a cada execução (EscreverAbaAvisos), e a mensagem
'   final avisa. Para refazer só esta parte, rode
'   DistribuirEditadoNasAbasTratamento com a aba EDITADO aberta.
' ================================================================================

' Macro principal. Fluxo: 0) prepara o Excel; 1) acha a aba PURO; 2) mapeia os
' cabeçalhos; 3) define o layout de saída; 4) avisa cabeçalhos faltando;
' 5) descobre o mês para o nome da aba; 6) cria a aba; 7) cabeçalho;
' 8) copia linha a linha; 9) aparência; 10) cola internos e externos nas abas
' "Tratamento - Internos" / "Tratamento - Externos" (DistribuirNasAbasTratamento). Os rótulos Finalizar/TratarErro, no fim,
' garantem que o Excel volte ao normal mesmo se der erro.
Sub PURO_Para_EDITADO()

    Dim wbAtual As Workbook
    Dim wsPuro As Worksheet
    Dim wsEditado As Worksheet
    Dim headerMap As Object          ' Dictionary: nome do cabeçalho (Trim) -> nº da coluna na PURO
    Dim colunasFaltando As String    ' Acumula avisos de cabeçalhos não encontrados

    Dim targetHeaders() As Variant   ' Cabeçalhos finais, na ordem exata da EDITADO
    Dim sourceKeys() As Variant      ' Nome do cabeçalho correspondente na PURO ("" = coluna manual/em branco)
    Dim convertFlag() As Variant     ' True = converter "X" -> "SIM" nesta coluna

    Dim i As Long, r As Long, lastColPuro As Long, lastRowPuro As Long
    Dim srcCol As Long
    Dim valorOriginal As String
    Dim statusBarAntes As Boolean

    Dim colDataApuracao As Long
    Dim dataReferencia As Date
    Dim temDataValida As Boolean
    Dim mesAno As String
    Dim nomeAbaFinal As String
    Dim sufixo As Long
    Dim monthAbbrev As Variant

    ' Qualquer erro não previsto pula para TratarErro (fim da rotina), que mostra a
    ' mensagem e restaura o Excel.
    On Error GoTo TratarErro

    ' ----------------------------------------------------------------------
    ' 0) Preparação: desliga atualizações de tela/cálculo para performance
    '    e para evitar "piscar" a tela durante a execução.
    ' ----------------------------------------------------------------------
    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual
    Application.DisplayAlerts = False
    statusBarAntes = Application.DisplayStatusBar
    Application.DisplayStatusBar = True

    Set wbAtual = ThisWorkbook

    ' ----------------------------------------------------------------------
    ' 1) Confirma que a aba PURO existe
    ' ----------------------------------------------------------------------
    On Error Resume Next
    Set wsPuro = wbAtual.Sheets("PURO")
    On Error GoTo TratarErro
    If wsPuro Is Nothing Then
        MsgBox "Não encontrei uma aba chamada 'PURO' nesta pasta de trabalho." & vbCrLf & _
               "Verifique o nome da aba e tente novamente.", vbCritical, "Aba não encontrada"
        GoTo Finalizar
    End If

    ' ----------------------------------------------------------------------
    ' 2) Mapeia os cabeçalhos da PURO (linha 1) pelo NOME, ignorando espaços
    '    extras no início/fim (a exportação do sistema costuma vir com
    '    espaços de preenchimento nos nomes das colunas).
    ' ----------------------------------------------------------------------
    Set headerMap = CreateObject("Scripting.Dictionary")
    lastColPuro = wsPuro.Cells(1, wsPuro.Columns.Count).End(xlToLeft).Column

    Dim chave As String
    For i = 1 To lastColPuro
        chave = Trim(CStr(wsPuro.Cells(1, i).Value))
        If chave <> "" Then
            If Not headerMap.Exists(chave) Then
                headerMap.Add chave, i
            End If
        End If
    Next i

    If Not headerMap.Exists("Nome") Then
        MsgBox "Não encontrei a coluna 'Nome' no cabeçalho da PURO. Não é possível continuar.", _
               vbCritical, "Cabeçalho obrigatório ausente"
        GoTo Finalizar
    End If

    lastRowPuro = wsPuro.Cells(wsPuro.Rows.Count, headerMap("Nome")).End(xlUp).Row
    If lastRowPuro < 2 Then
        MsgBox "A aba PURO não tem linhas de dados (apenas cabeçalho).", vbExclamation, "Nada a processar"
        GoTo Finalizar
    End If

    ' ----------------------------------------------------------------------
    ' 3) Define o layout final: cabeçalho exato, de qual cabeçalho da PURO
    '    ele vem, e se precisa converter X -> SIM.
    '    (Ordem = ordem das colunas A, B, C... na aba final)
    '
    '    Estes 3 arrays trabalham em conjunto, posição a posição (targetHeaders(i)
    '    corresponde a sourceKeys(i) corresponde a convertFlag(i)):
    '      targetHeaders(i) = nome da coluna na aba EDITADO (o que vai ser ESCRITO)
    '      sourceKeys(i)    = nome do cabeçalho a procurar na aba PURO (de ONDE vem o
    '                         valor); string vazia "" = não existe na PURO, é uma coluna
    '                         de preenchimento manual (Gestor/Situação/Tratamento/
    '                         Pontonet) que fica em branco para o RH preencher depois
    '      convertFlag(i)   = True nas colunas que guardam "marcação de intervalo"
    '                         (Intra/Inter/Marcações Impares/Horas Excedentes/Extras e
    '                         Faltas): a PURO grava "X" quando a condição ocorreu, e
    '                         aqui isso é convertido para "SIM" (mais legível para quem
    '                         só olha a planilha, sem precisar saber o código do sistema)
    ' ----------------------------------------------------------------------
    targetHeaders = Array( _
        "Matricula", _
        "Nome", _
        "Gestor", _
        "Situação", _
        "Tratamento", _
        "Pontonet", _
        "Dt.Apuraç.", _
        "Marcações", _
        "Extras", _
        "Faltas", _
        "Extra 100%", _
        "Qtd. Horas Pagas", _
        "Intra", _
        "Inter", _
        "Marcações Impares", _
        "Horas Excedentes", _
        "Extras e Faltas", _
        "Refeição fora de Escala")

    ' As 4 strings vazias abaixo correspondem, nesta ordem, às colunas
    ' Gestor, Situação, Tratamento e Pontonet - preenchimento manual,
    ' sem coluna de origem na PURO.
    sourceKeys = Array( _
        "Cadastro", _
        "Nome", _
        "", _
        "", _
        "", _
        "", _
        "Dt.Apuraç.", _
        "Marcações", _
        "Extras", _
        "Faltas", _
        "Extra 100%", _
        "Qtd. Horas Pagas", _
        "Intrajornada", _
        "Interjornada", _
        "Marcações Impares", _
        "Horas Excedentes", _
        "Extras e Faltas", _
        "Refeição fora de Escala")

    convertFlag = Array(False, False, False, False, False, False, False, False, _
                         False, False, False, False, True, True, True, True, True, False)

    ' ----------------------------------------------------------------------
    ' 4) Confere se todos os cabeçalhos esperados existem na PURO.
    '    Se algum não existir, avisa (mas não trava) - a coluna ficará
    '    em branco na aba final.
    ' ----------------------------------------------------------------------
    For i = 0 To UBound(sourceKeys)
        If sourceKeys(i) <> "" Then
            If Not headerMap.Exists(sourceKeys(i)) Then
                colunasFaltando = colunasFaltando & "- """ & sourceKeys(i) & """ (esperado para a coluna """ & targetHeaders(i) & """)" & vbCrLf
            End If
        End If
    Next i

    If colunasFaltando <> "" Then
        MsgBox "Atenção: os cabeçalhos abaixo NÃO foram encontrados na aba PURO." & vbCrLf & _
               "As colunas correspondentes ficarão em branco na aba gerada:" & vbCrLf & vbCrLf & _
               colunasFaltando, vbExclamation, "Cabeçalhos não encontrados"
    End If

    ' ----------------------------------------------------------------------
    ' 5) Descobre a competência (mês/ano) para nomear a aba automaticamente,
    '    usando a data de apuração MAIS RECENTE encontrada na PURO.
    '    Isso evita depender da data do sistema (relógio do PC) e reflete
    '    o período real dos dados importados.
    ' ----------------------------------------------------------------------
    monthAbbrev = Array("JAN", "FEV", "MAR", "ABR", "MAI", "JUN", _
                         "JUL", "AGO", "SET", "OUT", "NOV", "DEZ")

    temDataValida = False
    If headerMap.Exists("Dt.Apuraç.") Then
        colDataApuracao = headerMap("Dt.Apuraç.")
        For r = 2 To lastRowPuro
            If IsDate(wsPuro.Cells(r, colDataApuracao).Value) Then
                If Not temDataValida Then
                    dataReferencia = CDate(wsPuro.Cells(r, colDataApuracao).Value)
                    temDataValida = True
                ElseIf CDate(wsPuro.Cells(r, colDataApuracao).Value) > dataReferencia Then
                    dataReferencia = CDate(wsPuro.Cells(r, colDataApuracao).Value)
                End If
            End If
        Next r
    End If

    If temDataValida Then
        mesAno = monthAbbrev(Month(dataReferencia) - 1) & Format(dataReferencia, "yy")
    Else
        ' Nenhuma data válida encontrada na PURO -> usa a data/hora atual do
        ' sistema como último recurso, para garantir que a macro NUNCA trave
        ' por falta de nome de aba.
        mesAno = monthAbbrev(Month(Date) - 1) & Format(Date, "yy") & "_" & Format(Now, "hhmmss")
    End If

    nomeAbaFinal = "EDITADO_" & mesAno

    ' ----------------------------------------------------------------------
    ' 6) Cria a aba final. Se já existir uma aba com esse nome (segunda
    '    execução no mesmo mês), pergunta o que fazer.
    ' ----------------------------------------------------------------------
    Set wsEditado = Nothing
    On Error Resume Next
    Set wsEditado = wbAtual.Sheets(nomeAbaFinal)
    On Error GoTo TratarErro

    If Not wsEditado Is Nothing Then
        Dim resposta As VbMsgBoxResult
        resposta = MsgBox("Já existe uma aba chamada '" & nomeAbaFinal & "'." & vbCrLf & vbCrLf & _
                           "Sim = apagar o conteúdo dela e gerar novamente" & vbCrLf & _
                           "Não = criar uma cópia com outro nome (ex.: " & nomeAbaFinal & " (2))" & vbCrLf & _
                           "Cancelar = interromper sem alterar nada", _
                           vbYesNoCancel + vbQuestion, "Aba já existe")

        Select Case resposta
            Case vbYes
                wsEditado.Cells.Clear
            Case vbNo
                GoTo CriarComSufixo
            Case vbCancel
                MsgBox "Operação cancelada pelo usuário. Nada foi alterado.", vbInformation, "Cancelado"
                GoTo Finalizar
        End Select
    Else
        Set wsEditado = wbAtual.Sheets.Add(After:=wsPuro)
        wsEditado.Name = nomeAbaFinal
    End If

    ' Se chegou aqui, a aba já está pronta: pula o bloco CriarComSufixo, que só é
    ' usado quando o usuário escolheu "Não" (criar cópia numerada).
    GoTo PularCriacaoComSufixo

CriarComSufixo:
    ' Ponto auxiliar: cria a aba com sufixo numérico (2), (3)... quando o
    ' usuário optou por não sobrescrever a aba já existente.
    On Error Resume Next
    Set wsEditado = Nothing
    sufixo = 2
    Do
        Set wsEditado = wbAtual.Sheets(nomeAbaFinal & " (" & sufixo & ")")
        If wsEditado Is Nothing Then Exit Do
        sufixo = sufixo + 1
        Set wsEditado = Nothing
    Loop
    On Error GoTo TratarErro
    Set wsEditado = wbAtual.Sheets.Add(After:=wsPuro)
    wsEditado.Name = nomeAbaFinal & " (" & sufixo & ")"

PularCriacaoComSufixo:

    ' ----------------------------------------------------------------------
    ' 7) Escreve o cabeçalho
    ' ----------------------------------------------------------------------
    For i = 0 To UBound(targetHeaders)
        wsEditado.Cells(1, i + 1).Value = targetHeaders(i)
    Next i
    wsEditado.Rows(1).Font.Bold = True

    ' ----------------------------------------------------------------------
    ' 8) Copia e transforma linha a linha.
    '    Como cada linha da PURO é tratada de forma independente (sem
    '    depender de uma linha equivalente em execuções anteriores), a
    '    macro já funciona corretamente mesmo com admissões/desligamentos
    '    entre um mês e outro: simplesmente gera uma linha nova para cada
    '    linha existente na PURO, sejam quantas forem.
    ' ----------------------------------------------------------------------
    Dim linhaDestino As Long
    linhaDestino = 2

    For r = 2 To lastRowPuro

        Application.StatusBar = "Processando linha " & r & " de " & lastRowPuro & "..."

        ' Para cada linha de dado da PURO (r), percorre a lista de colunas de destino (i) e, para
        ' cada uma, escreve na aba EDITADO (linha "linhaDestino", coluna "i + 1") o valor
        ' correspondente da PURO (linha r, coluna "srcCol" — descoberta via headerMap, o dicionário
        ' "nome do cabeçalho -> nº da coluna" montado no passo 2). Ou seja: para cada colaborador
        ' (linha), refaz a mesma correspondência coluna-a-coluna definida no passo 3 acima.
        For i = 0 To UBound(sourceKeys)

            If sourceKeys(i) = "" Then
                ' Coluna manual (Gestor, Situação, Tratamento, Pontonet) -> fica em branco
                ' (não faz nada aqui de propósito)
            Else
                If headerMap.Exists(sourceKeys(i)) Then
                    srcCol = headerMap(sourceKeys(i))

                    If convertFlag(i) Then
                        ' -----------------------------------------------------
                        ' Colunas de flag: valor é "" (vazio/espaços) ou
                        ' começa com "X". Convertemos "X" -> "SIM" (sem os
                        ' espaços de preenchimento que vinham depois do "X");
                        ' qualquer outro valor sai sem espaços nas pontas, e
                        ' célula só com espaços sai vazia de verdade.
                        ' -----------------------------------------------------
                        valorOriginal = CStr(LimparTexto(wsPuro.Cells(r, srcCol).Value))
                        If Left(valorOriginal, 1) = "X" Then
                            wsEditado.Cells(linhaDestino, i + 1).Value = "SIM"
                        ElseIf valorOriginal <> "" Then
                            wsEditado.Cells(linhaDestino, i + 1).Value = valorOriginal
                        End If
                    Else
                        ' Cópia direta do valor (mantém tipo: data, hora e
                        ' número continuam como estão; só TEXTO passa por
                        ' LimparTexto, que tira os espaços do fim do nome,
                        ' das marcações etc.)
                        wsEditado.Cells(linhaDestino, i + 1).Value = LimparTexto(wsPuro.Cells(r, srcCol).Value)
                        ' Copia também o formato de número (datas e horas)
                        wsEditado.Cells(linhaDestino, i + 1).NumberFormat = _
                            wsPuro.Cells(r, srcCol).NumberFormat
                    End If
                End If
            End If

        Next i

        linhaDestino = linhaDestino + 1
    Next r

    ' ----------------------------------------------------------------------
    ' 9) Ajustes finais de aparência
    ' ----------------------------------------------------------------------
    wsEditado.Columns.AutoFit
    wsEditado.Rows(1).AutoFilter

    ' ----------------------------------------------------------------------
    ' 10) Cola os colaboradores nas abas de tratamento (pedido do RH, 29/10):
    '     internos em "Tratamento - Internos" e externos em "Tratamento -
    '     Externos", conforme a coluna "Tipo de trabalho" da aba ORG. Ver
    '     DistribuirNasAbasTratamento, mais abaixo.
    ' ----------------------------------------------------------------------
    Dim resumoDistribuicao As String
    resumoDistribuicao = DistribuirNasAbasTratamento(wbAtual, wsEditado)

    Application.StatusBar = False
    MsgBox "Concluído! " & (linhaDestino - 2) & " linha(s) transferida(s) da PURO para a aba '" & _
           wsEditado.Name & "'." & vbCrLf & vbCrLf & resumoDistribuicao, vbInformation, "Processo finalizado"

Finalizar:
    ' Restaura o Excel ao estado normal, mesmo se algo tiver falhado
    Application.ScreenUpdating = True
    Application.Calculation = xlCalculationAutomatic
    Application.DisplayAlerts = True
    Application.DisplayStatusBar = statusBarAntes
    Application.StatusBar = False
    Exit Sub

' Rótulo de erro: só é alcançado via "On Error GoTo TratarErro". Mostra o erro e
' a linha da PURO em que estava, e volta para Finalizar.
TratarErro:
    MsgBox "Ocorreu um erro inesperado durante o processamento." & vbCrLf & _
           "Erro " & Err.Number & ": " & Err.Description & vbCrLf & _
           "Linha aproximada: " & r, vbCritical, "Erro na macro"
    Resume Finalizar

End Sub

' ================================================================================
' LimparTexto
' --------------------------------------------------------------------------------
' Tira os espaços das pontas de um valor de TEXTO (inclusive o espaço
' "não-quebrável", Chr(160), que exportações de sistema às vezes usam no
' lugar do espaço normal). Valores que não são texto (datas, horas, números)
' voltam intactos, para não perder o tipo nem o formato.
' Texto que só tinha espaços vira Empty, para a célula ficar vazia de verdade
' (senão CONT.VALORES/COUNTA e filtros de "(Vazias)" a contariam como
' preenchida).
' ================================================================================
Private Function LimparTexto(ByVal valor As Variant) As Variant
    Dim txt As String

    If VarType(valor) <> vbString Then
        LimparTexto = valor
        Exit Function
    End If

    txt = Trim$(Replace(valor, Chr(160), " "))
    If txt = "" Then
        LimparTexto = Empty
    Else
        LimparTexto = txt
    End If
End Function

' ================================================================================
' DistribuirEditadoNasAbasTratamento  (pode ser rodada sozinha, Alt+F8)
' --------------------------------------------------------------------------------
' Refaz só o passo 10: com uma aba EDITADO_... aberta (aba ativa), cola os
' internos e os externos nas abas de tratamento. Útil quando o ORG foi
' corrigido depois de rodar a PURO_Para_EDITADO.
' ================================================================================
Sub DistribuirEditadoNasAbasTratamento()
    Dim wsOrigem As Worksheet, resumoFinal As String
    Set wsOrigem = ActiveSheet
    If UCase$(Left$(wsOrigem.Name, 7)) <> "EDITADO" Then
        MsgBox "Abra (clique) a aba EDITADO_... antes de rodar esta macro.", vbExclamation, "Aba errada"
        Exit Sub
    End If
    On Error GoTo FalhouDistribuir
    Application.ScreenUpdating = False
    resumoFinal = DistribuirNasAbasTratamento(wsOrigem.Parent, wsOrigem)
    Application.ScreenUpdating = True
    MsgBox resumoFinal, vbInformation, "Abas de tratamento"
    Exit Sub
FalhouDistribuir:
    Application.ScreenUpdating = True
    MsgBox "Erro " & Err.Number & ": " & Err.Description, vbCritical, "Erro na macro"
End Sub

' ================================================================================
' DistribuirNasAbasTratamento
' --------------------------------------------------------------------------------
' Separa as linhas da EDITADO em internos e externos (coluna "Tipo de trabalho"
' do ORG) e cola cada grupo na sua aba de tratamento. Devolve o texto do resumo
' para a mensagem final. Não trava se faltar alguma aba: só avisa no resumo.
' ================================================================================
Private Function DistribuirNasAbasTratamento(wb As Workbook, wsEd As Worksheet) As String
    Dim wsOrg As Worksheet, wsInt As Worksheet, wsExt As Worksheet
    Dim colEd As Object, colOrg As Object
    Dim orgPorMat As Object, orgPorNome As Object
    Dim linhasInt As Collection, linhasExt As Collection
    Dim qtdSemTipo As Long, jaInt As Long, jaExt As Long
    Dim ultEd As Long, r As Long, k As String, tipoTxt As String
    Dim dadosOrg As Variant
    Dim resumo As String

    ' --- aba ORG: a primeira cujo nome começa com "ORG" e que tem Matricula e
    '     "Tipo de trabalho" na linha 1
    Dim ws As Worksheet
    For Each ws In wb.Worksheets
        If UCase$(Left$(Trim$(ws.Name), 3)) = "ORG" Then
            Set colOrg = MapaCabecalhoNorm(ws)
            If colOrg.Exists("MATRICULA") And ColunaTipoTrabalho(colOrg) > 0 Then
                Set wsOrg = ws
                Exit For
            End If
        End If
    Next ws
    If wsOrg Is Nothing Then
        DistribuirNasAbasTratamento = "As abas de tratamento NÃO foram preenchidas: não achei a aba ORG " & _
            "com as colunas ""Matricula"" e ""Tipo de trabalho"" na linha 1."
        Exit Function
    End If

    ' --- abas de destino
    Set wsInt = AchaAbaTratamento(wb, "INTERN", "- I")
    Set wsExt = AchaAbaTratamento(wb, "EXTERN", "- E")
    If Not wsInt Is Nothing Then LimparFiltroDaAba wsInt
    If Not wsExt Is Nothing Then LimparFiltroDaAba wsExt

    ' --- lê o ORG: matrícula -> Array(tipo de trabalho, cargo, gestor);
    '     o mesmo pelo nome, para quem está com a matrícula em erro (#N/A).
    '     Matrícula repetida: vale a primeira linha (como no GerarCSVPonto).
    LimparFiltroDaAba wsOrg
    Set orgPorMat = CreateObject("Scripting.Dictionary")
    Set orgPorNome = CreateObject("Scripting.Dictionary")
    Dim colOMat As Long, colONome As Long, colOTipo As Long, colOCargo As Long, colOGestor As Long
    colOMat = colOrg("MATRICULA")
    colONome = ValorOuZero(colOrg, "COLABORADOR")
    colOTipo = ColunaTipoTrabalho(colOrg)
    colOCargo = ValorOuZero(colOrg, "CARGO")
    colOGestor = ValorOuZero(colOrg, "GESTOR")
    Dim ultOrg As Long
    ultOrg = UltimaLinhaDaAba(wsOrg)
    For r = 2 To ultOrg
        Dim cargoOrg As String, gestorOrg As String
        cargoOrg = "": gestorOrg = ""
        If colOCargo > 0 Then cargoOrg = TextoDaCelula(wsOrg.Cells(r, colOCargo).Value)
        If colOGestor > 0 Then gestorOrg = TextoDaCelula(wsOrg.Cells(r, colOGestor).Value)
        dadosOrg = Array(TextoDaCelula(wsOrg.Cells(r, colOTipo).Value), cargoOrg, gestorOrg)
        k = ChaveDaMatricula(wsOrg.Cells(r, colOMat).Value)
        If k <> "" Then
            If Not orgPorMat.Exists(k) Then orgPorMat.Add k, dadosOrg
        End If
        If colONome > 0 Then
            k = NormTexto(TextoDaCelula(wsOrg.Cells(r, colONome).Value))
            If k <> "" Then
                If Not orgPorNome.Exists(k) Then orgPorNome.Add k, dadosOrg
            End If
        End If
    Next r

    ' --- separa as linhas da EDITADO
    Set colEd = MapaCabecalhoNorm(wsEd)
    Set linhasInt = New Collection
    Set linhasExt = New Collection
    ultEd = UltimaLinhaDaAba(wsEd)
    ' avisos: uma linha por pessoa com o que falta no ORG (aba "Avisos ORG", 29/10)
    Dim avisos As Object, faltaTxt As String, matTxt As String, nomeTxt As String, chavePes As String
    Set avisos = CreateObject("Scripting.Dictionary")
    Dim infoOrg As Variant, achou As Boolean, achouPeloNome As Boolean, vaiColar As Boolean
    For r = 2 To ultEd
        achou = False: achouPeloNome = False
        matTxt = "": nomeTxt = ""
        If colEd.Exists("MATRICULA") Then matTxt = TextoDaCelula(wsEd.Cells(r, colEd("MATRICULA")).Value)
        If colEd.Exists("NOME") Then nomeTxt = TextoDaCelula(wsEd.Cells(r, colEd("NOME")).Value)
        k = ChaveDaMatricula(matTxt)
        If k <> "" Then
            If orgPorMat.Exists(k) Then infoOrg = orgPorMat(k): achou = True
        End If
        If Not achou Then
            k = NormTexto(nomeTxt)
            If k <> "" Then
                If orgPorNome.Exists(k) Then infoOrg = orgPorNome(k): achou = True: achouPeloNome = True
            End If
        End If
        tipoTxt = ""
        If achou Then tipoTxt = NormTexto(CStr(infoOrg(0)))
        vaiColar = achou And (InStr(tipoTxt, "EXTERN") > 0 Or InStr(tipoTxt, "INTERN") > 0)
        If achou And InStr(tipoTxt, "EXTERN") > 0 Then
            linhasExt.Add Array(r, infoOrg)
        ElseIf achou And InStr(tipoTxt, "INTERN") > 0 Then
            linhasInt.Add Array(r, infoOrg)
        Else
            ' fora do ORG ou sem "Tipo de trabalho": não cola, pinta de amarelo
            wsEd.Rows(r).Interior.Color = RGB(255, 235, 156)
            qtdSemTipo = qtdSemTipo + 1
        End If

        ' o que falta para esta pessoa
        faltaTxt = ""
        If Not achou Then
            faltaTxt = "Não está no ORG (nem pela matrícula nem pelo nome)"
        Else
            If achouPeloNome And matTxt <> "" Then faltaTxt = "Matrícula " & matTxt & " não está no ORG (achado só pelo nome)"
            If tipoTxt = "" Then
                faltaTxt = faltaTxt & IIf(faltaTxt = "", "", "; ") & "Falta o Tipo de trabalho"
            ElseIf Not vaiColar Then
                faltaTxt = faltaTxt & IIf(faltaTxt = "", "", "; ") & "Tipo de trabalho """ & infoOrg(0) & """ não é Interno nem Externo"
            End If
            If CStr(infoOrg(1)) = "" Then faltaTxt = faltaTxt & IIf(faltaTxt = "", "", "; ") & "Falta o Cargo"
            If CStr(infoOrg(2)) = "" Then faltaTxt = faltaTxt & IIf(faltaTxt = "", "", "; ") & "Falta o Gestor"
        End If
        If faltaTxt <> "" Then
            chavePes = IIf(ChaveDaMatricula(matTxt) <> "", "M" & ChaveDaMatricula(matTxt), "N" & NormTexto(nomeTxt))
            If Not avisos.Exists(chavePes) Then
                avisos.Add chavePes, Array(matTxt, nomeTxt, faltaTxt, IIf(vaiColar, "Sim", "Não (está em amarelo na " & wsEd.Name & ")"))
            End If
        End If
    Next r
    EscreverAbaAvisos wb, avisos

    ' --- se alguma aba de destino já tem linhas, pergunta uma vez só. A macro é
    '     usada todo dia (29/10): ela NUNCA apaga nada das abas de tratamento;
    '     só cola embaixo (OK) ou não cola (Cancelar).
    Dim modo As VbMsgBoxResult
    Dim jaTem As Boolean
    If Not wsInt Is Nothing Then
        If UltimaLinhaDados(wsInt) > 1 Then jaTem = True
    End If
    If Not wsExt Is Nothing Then
        If UltimaLinhaDados(wsExt) > 1 Then jaTem = True
    End If
    If jaTem Then
        Application.ScreenUpdating = True
        modo = MsgBox("As abas de tratamento já têm linhas preenchidas." & vbCrLf & vbCrLf & _
                      "OK = colar as linhas novas EMBAIXO das que já existem (nada é apagado)" & vbCrLf & _
                      "Cancelar = não colar nada nas abas de tratamento", _
                      vbOKCancel + vbQuestion, "Colar nas abas de tratamento")
        Application.ScreenUpdating = False
        If modo = vbCancel Then
            DistribuirNasAbasTratamento = "Abas de tratamento: nada foi colado (você escolheu Cancelar)." & _
                TextoAvisos(avisos)
            Exit Function
        End If
    End If

    ' --- cola
    If wsInt Is Nothing Then
        resumo = "Não achei a aba ""Tratamento - Internos"": " & linhasInt.Count & " interno(s) não foram colados."
    Else
        jaInt = ColarLinhasNaAba(wsEd, colEd, linhasInt, wsInt)
        resumo = (linhasInt.Count - jaInt) & " interno(s) colado(s) na aba '" & wsInt.Name & "'." & _
            IIf(jaInt > 0, " " & jaInt & " já estava(m) lá e não foi(ram) colado(s) de novo.", "")
    End If
    If wsExt Is Nothing Then
        resumo = resumo & vbCrLf & "Não achei a aba ""Tratamento - Externos"": " & linhasExt.Count & " externo(s) não foram colados."
    Else
        jaExt = ColarLinhasNaAba(wsEd, colEd, linhasExt, wsExt)
        resumo = resumo & vbCrLf & (linhasExt.Count - jaExt) & " externo(s) colado(s) na aba '" & wsExt.Name & "'." & _
            IIf(jaExt > 0, " " & jaExt & " já estava(m) lá e não foi(ram) colado(s) de novo.", "")
    End If
    If qtdSemTipo > 0 Then
        resumo = resumo & vbCrLf & vbCrLf & qtdSemTipo & " linha(s) NÃO foram coladas (em amarelo na aba '" & _
            wsEd.Name & "'): a pessoa não está no ORG ou está sem ""Tipo de trabalho""."
    End If
    DistribuirNasAbasTratamento = resumo & TextoAvisos(avisos)
End Function

' Cola as linhas escolhidas da EDITADO numa aba de tratamento, EMBAIXO das que
' já existem (nunca apaga nada), coluna por coluna pelo nome do cabeçalho da
' aba de destino (linha 1). Funciona com a aba em formato de Tabela do Excel
' (ListObject) ou sem tabela.
' Linha que JÁ ESTÁ na aba (mesma matrícula + data + marcações) não é colada de
' novo: assim rodar duas vezes no mesmo dia, ou rodar
' DistribuirEditadoNasAbasTratamento depois de corrigir o ORG, não duplica nada.
' Devolve quantas linhas foram puladas por já estarem lá.
Private Function ColarLinhasNaAba(wsEd As Worksheet, colEd As Object, linhas As Collection, _
                                  wsDest As Worksheet) As Long
    Dim colDest As Object, lo As ListObject
    Dim ultCol As Long, c As Long, i As Long, linhaIni As Long, lin As Long
    Dim nomeCol As String, origemCol As String
    Dim formulas() As String
    Dim parLinha As Variant, rEd As Long, infoOrg As Variant

    LimparFiltroDaAba wsDest
    Set colDest = MapaCabecalhoNorm(wsDest)
    ultCol = wsDest.Cells(1, wsDest.Columns.Count).End(xlToLeft).Column

    ' Tabela do Excel com o cabeçalho na linha 1 (se houver)
    For Each lo In wsDest.ListObjects
        If lo.HeaderRowRange.Row = 1 Then Exit For
    Next lo

    ' Guarda as fórmulas da 1ª linha de dados (ex.: PROCX do Gestor/Cargo/
    ' Trabalho), só das colunas que NÃO vêm da EDITADO, para estender às linhas novas.
    ReDim formulas(1 To ultCol)
    For c = 1 To ultCol
        nomeCol = NormTexto(TextoDaCelula(wsDest.Cells(1, c).Value))
        If ColunaDaEditado(nomeCol, colEd) = "" Then
            If wsDest.Cells(2, c).HasFormula Then formulas(c) = wsDest.Cells(2, c).FormulaR1C1
        End If
    Next c

    If linhas.Count = 0 Then Exit Function

    ' linhas que já estão na aba (matrícula|data|marcações)
    Dim jaNaAba As Object, ultDados As Long, rr As Long, chaveLin As String
    Set jaNaAba = CreateObject("Scripting.Dictionary")
    ultDados = UltimaLinhaDados(wsDest)
    For rr = 2 To ultDados
        chaveLin = ChaveDaLinha(wsDest, rr, colDest, "MATRICULA", "DATA", "MARCACOES")
        If Not jaNaAba.Exists(chaveLin) Then jaNaAba.Add chaveLin, True
    Next rr

    ' primeira linha livre: logo depois da última com Matricula/Nome preenchido
    ' (se a Tabela do Excel já tem linhas vazias no fim, elas são aproveitadas)
    linhaIni = UltimaLinhaDados(wsDest) + 1
    If Not lo Is Nothing Then
        If linhaIni < lo.HeaderRowRange.Row + 1 Then linhaIni = lo.HeaderRowRange.Row + 1
    End If

    lin = linhaIni
    For i = 1 To linhas.Count
        parLinha = linhas(i)
        rEd = parLinha(0)
        infoOrg = parLinha(1)
        chaveLin = ChaveDaLinha(wsEd, rEd, colEd, "MATRICULA", "DT.APURAC.", "MARCACOES")
        If jaNaAba.Exists(chaveLin) Then
            ColarLinhasNaAba = ColarLinhasNaAba + 1
            GoTo ProximaLinhaColar
        End If
        jaNaAba.Add chaveLin, True
        For c = 1 To ultCol
            nomeCol = NormTexto(TextoDaCelula(wsDest.Cells(1, c).Value))
            origemCol = ColunaDaEditado(nomeCol, colEd)
            If origemCol <> "" Then
                wsDest.Cells(lin, c).Value = wsEd.Cells(rEd, colEd(origemCol)).Value
                wsDest.Cells(lin, c).NumberFormat = wsEd.Cells(rEd, colEd(origemCol)).NumberFormat
            ElseIf formulas(c) <> "" Then
                wsDest.Cells(lin, c).FormulaR1C1 = formulas(c)
            ElseIf nomeCol = "TRABALHO" Or nomeCol = "TIPO DE TRABALHO" Then
                wsDest.Cells(lin, c).Value = infoOrg(0)
            ElseIf nomeCol = "CARGO" Then
                wsDest.Cells(lin, c).Value = infoOrg(1)
            ElseIf nomeCol = "GESTOR" Then
                wsDest.Cells(lin, c).Value = infoOrg(2)
            End If
        Next c
        lin = lin + 1
ProximaLinhaColar:
    Next i

    ' Tabela do Excel: estica a tabela até a última linha colada
    If Not lo Is Nothing Then
        If lin - 1 > lo.HeaderRowRange.Row + lo.ListRows.Count Then
            lo.Resize wsDest.Range(lo.HeaderRowRange.Cells(1, 1), _
                wsDest.Cells(lin - 1, lo.HeaderRowRange.Column + lo.HeaderRowRange.Columns.Count - 1))
        End If
    End If
End Function

' "matrícula|data|marcações" de uma linha, para saber se ela já foi colada.
' Data como número (sem a hora), marcações sem espaços sobrando.
Private Function ChaveDaLinha(ws As Worksheet, ByVal r As Long, cols As Object, _
                              ByVal cMat As String, ByVal cData As String, ByVal cMarc As String) As String
    Dim m As String, d As String, mc As String, v As Variant
    If cols.Exists(cMat) Then m = ChaveDaMatricula(ws.Cells(r, cols(cMat)).Value)
    If cols.Exists(cData) Then
        v = ws.Cells(r, cols(cData)).Value
        If IsDate(v) Then
            d = CStr(CLng(Int(CDbl(CDate(v)))))
        Else
            d = TextoDaCelula(v)
        End If
    End If
    If cols.Exists(cMarc) Then mc = NormTexto(TextoDaCelula(ws.Cells(r, cols(cMarc)).Value))
    ChaveDaLinha = m & "|" & d & "|" & mc
End Function

' Aba "Avisos ORG": uma linha por pessoa da EDITADO com informação faltando no
' ORG (não está lá, sem Tipo de trabalho, sem Cargo, sem Gestor, matrícula
' diferente). É refeita a cada execução: mostra só os avisos da última vez.
' Sem nenhum aviso, a aba fica com a frase "Nenhum aviso".
Private Sub EscreverAbaAvisos(wb As Workbook, avisos As Object)
    Dim ws As Worksheet, k As Variant, lin As Long, aviso As Variant, abaAntes As Object
    Set abaAntes = wb.ActiveSheet
    On Error Resume Next
    Set ws = wb.Worksheets("Avisos ORG")
    On Error GoTo 0
    If ws Is Nothing Then
        Set ws = wb.Worksheets.Add(After:=wb.Worksheets(wb.Worksheets.Count))
        ws.Name = "Avisos ORG"
    End If
    ws.Cells.Clear
    ws.Range("A1:D1").Value = Array("Matrícula", "Nome", "O que está faltando no ORG", "Foi colado na aba de tratamento?")
    ws.Rows(1).Font.Bold = True
    lin = 2
    If avisos.Count = 0 Then
        ws.Cells(2, 1).Value = "Nenhum aviso: todas as pessoas da última execução estão completas no ORG (" & Format(Now, "dd/mm/yyyy hh:nn") & ")."
    Else
        For Each k In avisos.Keys
            aviso = avisos(k)
            ws.Cells(lin, 1).NumberFormat = "@"
            ws.Cells(lin, 1).Value = aviso(0)
            ws.Cells(lin, 2).Value = aviso(1)
            ws.Cells(lin, 3).Value = aviso(2)
            ws.Cells(lin, 4).Value = aviso(3)
            lin = lin + 1
        Next k
    End If
    ws.Columns("A:D").AutoFit
    ' com aviso, a aba de avisos fica aberta na frente; sem aviso, volta para onde estava
    If avisos.Count > 0 Then ws.Activate Else abaAntes.Activate
End Sub

' Trecho da mensagem final sobre a aba "Avisos ORG".
Private Function TextoAvisos(avisos As Object) As String
    If avisos.Count = 0 Then Exit Function
    TextoAvisos = vbCrLf & vbCrLf & "ATENÇÃO: " & avisos.Count & " pessoa(s) com informação faltando no ORG. " & _
        "Veja a aba 'Avisos ORG' (pessoa e o que falta). Depois de corrigir o ORG, as linhas que não " & _
        "foram coladas podem ser coladas rodando DistribuirEditadoNasAbasTratamento."
End Function

' De qual coluna da EDITADO (nome normalizado) vem a coluna da aba de
' tratamento. "" = não vem da EDITADO (Check, Trabalho, Cargo, Gestor...).
' Gestor da EDITADO só vale se alguém preencheu (normalmente está em branco).
Private Function ColunaDaEditado(ByVal nomeDest As String, colEd As Object) As String
    Dim alvo As String
    Select Case nomeDest
        Case "", "CHECK", "TRABALHO", "TIPO DE TRABALHO", "CARGO", "GESTOR": alvo = ""
        Case "STATUS": alvo = "TRATAMENTO"
        Case "DATA": alvo = "DT.APURAC."
        Case Else: alvo = nomeDest
    End Select
    If alvo <> "" Then
        If Not colEd.Exists(alvo) Then alvo = ""
    End If
    ColunaDaEditado = alvo
End Function

' Acha a aba de tratamento: nome começando com "Tratamento" e contendo
' "Intern"/"Extern"; se não houver, uma aba cujo nome termina em "- I"/"- E".
Private Function AchaAbaTratamento(wb As Workbook, ByVal trecho As String, ByVal fimNome As String) As Worksheet
    Dim ws As Worksheet, nm As String
    For Each ws In wb.Worksheets
        nm = NormTexto(ws.Name)
        If Left$(nm, 10) = "TRATAMENTO" And InStr(nm, trecho) > 0 Then
            Set AchaAbaTratamento = ws
            Exit Function
        End If
    Next ws
    For Each ws In wb.Worksheets
        nm = NormTexto(ws.Name)
        If Right$(nm, Len(fimNome)) = fimNome Then
            Set AchaAbaTratamento = ws
            Exit Function
        End If
    Next ws
End Function

' Cabeçalho da linha 1 -> nº da coluna, com o nome sem acento, em maiúsculas
' e sem espaços sobrando ("Situação" -> "SITUACAO"). Vale a primeira coluna
' de cada nome.
Private Function MapaCabecalhoNorm(ws As Worksheet) As Object
    Dim d As Object, c As Long, ultCol As Long, nm As String
    Set d = CreateObject("Scripting.Dictionary")
    ultCol = ws.Cells(1, ws.Columns.Count).End(xlToLeft).Column
    For c = 1 To ultCol
        nm = NormTexto(TextoDaCelula(ws.Cells(1, c).Value))
        If nm <> "" Then
            If Not d.Exists(nm) Then d.Add nm, c
        End If
    Next c
    Set MapaCabecalhoNorm = d
End Function

' Coluna "Tipo de trabalho" do ORG (aceita também só "Trabalho").
Private Function ColunaTipoTrabalho(colOrg As Object) As Long
    If colOrg.Exists("TIPO DE TRABALHO") Then
        ColunaTipoTrabalho = colOrg("TIPO DE TRABALHO")
    ElseIf colOrg.Exists("TRABALHO") Then
        ColunaTipoTrabalho = colOrg("TRABALHO")
    End If
End Function

Private Function ValorOuZero(d As Object, ByVal chaveBusca As String) As Long
    If d.Exists(chaveBusca) Then ValorOuZero = d(chaveBusca)
End Function

' Matrícula como texto comparável: número sem zeros à esquerda; erro (#N/A)
' ou vazio = "".
Private Function ChaveDaMatricula(ByVal v As Variant) As String
    Dim t As String
    t = TextoDaCelula(v)
    If t = "" Then Exit Function
    If IsNumeric(t) Then t = CStr(CDbl(t))
    ChaveDaMatricula = t
End Function

' Texto de uma célula sem espaços nas pontas; erro do Excel (#N/A) vira "".
Private Function TextoDaCelula(ByVal v As Variant) As String
    If IsError(v) Then Exit Function
    If IsEmpty(v) Then Exit Function
    TextoDaCelula = Trim$(Replace(CStr(v), Chr(160), " "))
End Function

' Sem acento, maiúsculas, um espaço só entre as palavras.
Private Function NormTexto(ByVal t As String) As String
    Dim com As String, sem As String, i As Long
    com = "áàâãäéèêëíìîïóòôõöúùûüçÁÀÂÃÄÉÈÊËÍÌÎÏÓÒÔÕÖÚÙÛÜÇ"
    sem = "aaaaaeeeeiiiiooooouuuucAAAAAEEEEIIIIOOOOOUUUUC"
    For i = 1 To Len(com)
        t = Replace(t, Mid$(com, i, 1), Mid$(sem, i, 1))
    Next i
    t = UCase$(Trim$(Replace(t, Chr(160), " ")))
    Do While InStr(t, "  ") > 0
        t = Replace(t, "  ", " ")
    Loop
    NormTexto = t
End Function

' Última linha com qualquer coisa escrita na aba (não usa End(xlUp), que para
' na última linha VISÍVEL quando há filtro).
Private Function UltimaLinhaDaAba(ws As Worksheet) As Long
    Dim achado As Range
    Set achado = ws.Cells.Find(What:="*", LookIn:=xlFormulas, SearchOrder:=xlByRows, _
                               SearchDirection:=xlPrevious)
    If achado Is Nothing Then
        UltimaLinhaDaAba = 1
    Else
        UltimaLinhaDaAba = achado.Row
    End If
End Function

' Última linha com Matricula ou Nome preenchido numa aba de tratamento. Olha
' só essas duas colunas e só VALORES: se a aba tem fórmulas (PROCX do Gestor)
' puxadas até a linha 1000, as linhas só com fórmula não contam como dados.
Private Function UltimaLinhaDados(ws As Worksheet) As Long
    Dim colDest As Object, nomes As Variant, i As Long, achado As Range
    Set colDest = MapaCabecalhoNorm(ws)
    nomes = Array("MATRICULA", "NOME")
    UltimaLinhaDados = 1
    For i = 0 To 1
        If colDest.Exists(nomes(i)) Then
            Set achado = ws.Columns(colDest(nomes(i))).Find(What:="*", LookIn:=xlValues, _
                SearchOrder:=xlByRows, SearchDirection:=xlPrevious)
            If Not achado Is Nothing Then
                If achado.Row > UltimaLinhaDados Then UltimaLinhaDados = achado.Row
            End If
        End If
    Next i
End Function

' Tira o filtro da aba e das tabelas dela (senão colar e apagar pulam as
' linhas escondidas).
Private Sub LimparFiltroDaAba(ws As Worksheet)
    Dim lo As ListObject
    On Error Resume Next
    If ws.FilterMode Then ws.ShowAllData
    For Each lo In ws.ListObjects
        If Not lo.AutoFilter Is Nothing Then
            If lo.AutoFilter.FilterMode Then lo.AutoFilter.ShowAllData
        End If
    Next lo
    On Error GoTo 0
End Sub
